OpenAI Responses API 챗봇

브라우저에서 POST /v1/responses 요청과 멀티턴 input 구조를 실습합니다.

API 상태: 키 미설정

프로젝트 루트의 .env.local 파일에 VITE_OPENAI_API_KEY를 설정한 뒤 개발 서버를 재시작해 주세요.

모델
gpt-4.1-mini
누적 대화
0턴

메시지를 입력해 첫 요청을 보내 보세요

질문을 전송하면 이전 대화 내역 전체가 input 배열에 담겨 전달되므로 이어지는 질문에도 문맥에 맞게 답변합니다.

호출 주소
https://api.openai.com/v1/responses
사용 모델
gpt-4.1-mini
환경 변수
import.meta.env.VITE_OPENAI_API_KEY

Enter 키로 전송하고 Shift+Enter로 줄바꿈합니다. 브라우저 환경 변수는 외부에 노출되므로 실제 키가 포함된 빌드 결과물을 공개 배포하지 마세요.
